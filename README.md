# Base16 Grayscale for iTerm2

iTerm2 color schemes for the **Base16 Grayscale** palette, available in both Dark and Light variants.

## Color Schemes

- [`base16-grayscale.dark.256.itermcolors`](base16-grayscale.dark.256.itermcolors)
- [`base16-grayscale.light.256.itermcolors`](base16-grayscale.light.256.itermcolors)

## Installation

1. Clone or download this repository.
2. Open **iTerm2** Preferences (`⌘ + ,`).
3. Navigate to **Profiles** → **Colors**.
4. In the bottom-right corner, click **Color Presets...** → **Import...**.
5. Select `base16-grayscale.dark.256.itermcolors` and/or `base16-grayscale.light.256.itermcolors`.
6. Select the imported scheme from the **Color Presets...** dropdown.
